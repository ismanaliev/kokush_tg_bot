# KG Hostel Knowledge Base

## Правила приложения
- Хостелы-партнеры имеют приоритет в поиске
- Bulut Hostel всегда отображается первым
- Обновления доступности должны производиться ежедневно
- Скрытые листинги появляются через 24 часа без обновлений

## Инструкции по обновлению кроватей
- Используйте кнопки +1 и -1 для изменения количества доступных кроватей
- Общее количество кроватей устанавливается при создании хостела
- Цены указываются за ночь
- Обновления автоматически показывают хостел в поиске

## Верификация хостела
- Необходимо загрузить фотографии: туалет, кухня, спальная зона
- Хостел становится видимым только после верификации
- Администраторы проверяют фотографии перед активацией

## Оплата и бронирование
- Поддерживаются MBank и O!Dengi
- Загрузите скриншот транзакции для верификации
- Бронирование подтверждается после оплаты

## Поддержка пользователей
- AI-агент отвечает на основные вопросы
- Сложные проблемы перенаправляются живому оператору
- Контактная информация: support@kghostel.kg
